# `macubuntu` / Celina — v4.5 Architectural Roadmap (Post-v4.4.0 Feature Freeze)

`v4.4.0` is **feature-frozen** after clearing all QA audit findings (`0 P0`, `0 P1`, `215/215` passing tests across 24 suites). The three structural macOS-comparison seams and optional D-Bus / `io_uring` enhancements below are explicitly deferred to **`v4.5`** so they can be built cleanly on top of a verified, stable `v4.4.0` baseline.

---

## 1. Real-Time Filesystem Index Helper (The Spotlight / `mds` Seam)
- **Gap in v4.4.0:** `celina_pkg/spotlight_index.py` uses userspace periodic/event refreshes rather than continuous kernel filesystem notifications.
- **v4.5 Design:** Ship a lightweight, memory-bounded Rust helper using Linux `inotify` + `fanotify` watching user document directories (`~/Documents`, `~/Desktop`, `~/Downloads`, `~/Projects`) and streaming incremental metadata deltas directly into the private `0600` SQLite WAL FTS5 index (zero full-tree rescans, minimal RSS).

## 2. Declarative YAML Tool Contracts (The App Intents Seam)
- **Gap in v4.4.0:** Tool schemas, capabilities, risk tiers, and handlers live across Python structures verified by a 7-way Stage 00 parity gate.
- **v4.5 Design:** Co-locate a declarative YAML contract per tool (`name`, `tier`, `inputs`, `outputs`, `fs_scope`, `network_egress`, `undo_strategy`) read directly by `router.py`, `approval.py`, and `capabilities.py` — turning multi-registry parity into a single source of truth and enabling safer multi-step tool composition.

## 3. Hardware-Anchored Evidence Ledger (The Secure Enclave / SEP Seam)
- **Gap in v4.4.0:** `EvidenceLedger` seals its fail-closed anchor (`~/.config/celina/evidence_anchors/<sha>.anchor`, mode `0600`) in a separate directory from `ledger.jsonl`, blocking casual deletion or truncation. A determined local attacker with shell access could still delete both files.
- **v4.5 Design:** Seal the evidence anchor against **TPM 2.0 signed PCR 7 policy** (`systemd-creds encrypt --with-key=tpm2` using `--tpm2-public-key=` signed PCR policy, never brittle raw PCRs alone) so silent ledger deletion or bootloader tampering fails hardware unseal verification.

## 4. Installer-Substituted Per-UID D-Bus Policy & `io_uring` Memory Backend
- `v4.4.0` already removed deprecated `at_console="true"` from `system/dbus/org.macubuntu.Celina*.conf` in favor of explicit `<policy context="default">` interface allowlists backed by `dbus_service.py`'s runtime `GetConnectionUnixUser` peer-UID checks; `v4.5` adds optional installer-substituted numeric UID drop-ins during Stage 70 / `.deb` postinst (never shipping literal placeholders like `user="YOUR_UID"`).
- Benchmark optional `io_uring` (Turso/libSQL) storage acceleration against v4.4.0's proven SQLite WAL + `busy_timeout=5000` single-file `memory.db` baseline.
